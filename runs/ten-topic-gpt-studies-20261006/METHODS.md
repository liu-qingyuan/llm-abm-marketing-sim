# Ten-topic GPT/P0 research source bundle

This source bundle continues branch codex/ten-topic-full-pool-replay from 8bc3385, in the same managed worktree. It is not a new project and does not rewrite historical results. Run-local research code follows the previous index study's ownership pattern; public production contracts are unchanged.

- `merged_collection.py` derives from the immutable old index collector, preserves intent/settlement fsync, source/transport checks, exact per-user/message/client-condition identity, single-writer lock, original per-pair retries and unknown-stop semantics. The new preparation schema and explicit 2026-10-06 human approval replace the old finite overall call/fee caps. Total request/fee ceilings are null; five independent Pi GPT clients, P0/low/256/30s remain frozen.
- `live_study.py` reads/compiles the original seven arm definitions without writing the old run or importing its executable scripts. Arm selection/proxy formulas are reused exactly, with a new merged-network base cohort.
- `verify_collection.py` independently reconstructs accepted new records, real observed-model/usage facts, ledger ordinals, concurrency, bounded per-input attempts, overall coverage, bank bytes and actual known/unknown nominal accounting. A bank containing any unknown or missing candidate does not close.
- `offline_path_engine.py` and `fast_paths.py` use the original Kernel, but own explicit historical draw anchoring and full input matching. The cache checks all 30 time-step visible inputs once per immutable arm; it does not bypass exact matching or generate rule-based judgments. Independent verification does not call Kernel ranking/selection/commit helpers.
- `run_research.py` accepts only the independently closed real bank; runs all original 21 parameters × 100 seeds and seven arms × 100 seeds; resumes only hash/identity-matching persisted paths; verifies every path. Shared baseline and Local weights fixed/rebuilt equality are checked on all 100 realized paths, not inferred.
- `report_research.py` reopens every path and independently rechecks it before deriving per-path/arm/parameter and curve comparisons. Original df99 Monte Carlo intervals, parameter family 123, index family 120, epsilon 2pp and halfwidth target .5pp are retained. Differences mix network/sample/index/model-service epochs and are not pure causal effects.

Source inputs are explicitly bound in `formal-bank/preparation.json` and `preflight-final/protected-source-hashes.json`; no latest-directory discovery. The original parameter bank hash remains the draw anchor, separate from the new bank identity. Original/fixed-old samples are audited but not added as extra formal experiments. Four-model research, paper and canonical deployment are excluded.

Data/preparation/judgment/ledger/path files stay outside the Git source commit. Run-local tests require the actual independent preparation and original processed fixture inputs and are explicitly invoked, not part of the default public offline CI test discovery. Test judgments are marked UNIT_TEST_ONLY and never published as Formal results.
