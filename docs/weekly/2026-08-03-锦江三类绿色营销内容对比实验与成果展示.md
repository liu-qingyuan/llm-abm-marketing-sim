# 本周工作进展报告（2026.07.28-2026.08.03）：锦江三类绿色营销内容对比实验与成果展示

## 小结

> 本周统计周期：`2026.07.28-2026.08.03`；进展更新时间：`2026.08.03`。

本周主要把前期完成的锦江酒店绿色营销正式实验结果，整理成更便于查看、讲解和核对的研究成果：

- 围绕同一项“秸秆洗漱用品”绿色实践，对三类营销内容进行对比，分别突出环保责任、实用品质和材料创新，观察不同表达方式可能带来的互动差异；
- 正式实验使用 1,000 位研究样本用户。三类内容各完成 600 次仿真曝光，共 1,800 次；每次曝光都保留一份结合营销传播情境的正式判断，以及一份只参考用户基础信息的对照判断，共形成 3,600 条大语言模型判断，运行过程中没有失败记录；
- 正式判断中的模拟互动结果为：点赞 1,513 次、评论 76 次、分享 3 次、忽略 208 次。这些结果用于比较不同内容和不同用户群体在仿真环境中的传播表现，不代表 Douyin 用户真实发生了这些行为，也不能直接当作现实营销效果；
- 完成中英双语研究网页。网页可以在“实验机制说明”和“本次运行结果”两个视图之间切换，查看研究样本如何构成、内容如何推荐、模型如何判断用户行为，以及互动结果如何影响后续传播；同时保留用户、曝光、判断结果和汇总数据的下载入口；
- 将正式研究网页发布到 `https://abm.q1ngyuan.top/`，并完成电脑端和手机端检查。此次只改善成果展示，没有重新调用大语言模型，也没有修改原有实验结果；
