# 本周工作进展报告（2026.08.04-2026.08.10）：锦江营销传播稳健性分析与正式报告更新

## 小结

> 本周统计周期：`2026.08.04-2026.08.10`；进展更新时间：`2026.08.10`。

- 完成五张实验机制图及配套说明的更新，重点明确同一位用户可以同时进入多条营销内容的候选队列，以及用户对任一内容产生正向互动后，如何在下一批次影响三类内容的推荐。此次机制图更新只改善解释方式，没有改写前期已经形成的 3,600 条正式判断；
- 围绕推荐排序中的“用户与内容匹配度、用户之间的网络关联、前序互动反馈”三类因素，设计 19 组权重组合，并在固定的 1,000 位研究样本、3 条营销内容和 30 个传播批次上进行离线比较。多数权重组合的整体受众变化较小，但少数具体批次出现了较明显的推荐对象变化，说明总体趋势相对稳定的同时仍存在局部敏感环节；
- Prompt–Model 实验的实际设计是：环保责任、实用品质和材料创新三类营销内容中的每一类，都分别使用 P0、P1、P2、P3 四种信息等价但组织方式不同的 Prompt，再分别与 4 个大语言模型组合。其中 P0 是原始基线表达，P1 是同义改写，P2 调整了信息区块顺序，P3 增加了结构化判断提示。运行合同中记录为 `4 Prompt × 4 model = 16` 个实验单元，每个单元同时包含三类内容，因此应展开为 `3 类内容 × 4 Prompt × 4 model = 48` 个内容–Prompt–模型结果切片。每个切片包含 600 次用户判断，合计获得 28,800 条有效判断，实际请求 29,402 次，运行过程中没有最终失败记录；
- 对提示词、模型及其组合差异进行统一比较。在 189 项预设比较中，33 项达到本研究设定的“具有实际意义的差异”标准，156 项属于较小的观测差异。这说明部分仿真结果会受到提示词组织方式或模型选择影响，因此正式结论需要同时说明具体内容、Prompt 和模型条件，不能只报告跨内容汇总结果；
- 当前研究网页存在需要继续修正的展示与追溯问题：网页虽然提供了 `message_1/2/3` 选择器，并在每个模型图中绘制 P0–P3 四条曲线，但没有直接写出三类营销内容各自对应的名称，也没有并列解释每一类内容下四种 Prompt 的具体组织差异，更没有正面展示上述 48 个结果切片之间的对应关系。页面把实验概括成“16 cells”，容易让读者误以为每类内容没有分别使用四种 Prompt；这是当前报告的展示 Bug，不能视为已经解释完整；
- 已将部分新增稳健性结果与原有传播机制、正式运行证据、用户基础信息对照判断和传播门槛分析整合到同一研究网页，并发布到 `https://abm.q1ngyuan.top/`。

上述结果仍是固定研究样本和固定社交网络中的仿真观测，不代表 Douyin 用户真实发生的互动，也不能直接解释为因果关系、模型准确率或对全部用户群体都稳健。

下一步将优先修正网页中的 Prompt 展示与证据追溯问题：用三类营销内容的实际名称替代抽象的 `message_1/2/3`，在每类内容下并列说明 P0–P3 四种 Prompt 的版本、组织方式和等价边界，展示完整的 48 个内容–Prompt–模型结果切片，并核对每项结果与对应 message、Prompt 和 model 的绑定关系。如果进一步审计发现底层证据不足以证明某一对应关系，则不使用推断补齐，而是另行提出正式实验修正方案。完成上述问题后，再分析推荐权重变化中差异较大的局部传播批次，并把结果整理成论文或阶段汇报中的方法、结果和研究限制部分。
