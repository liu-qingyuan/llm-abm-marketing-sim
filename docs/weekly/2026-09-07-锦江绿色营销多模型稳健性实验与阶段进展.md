# 本周工作进展报告（2026.09.01-2026.09.07）：锦江绿色营销多模型稳健性实验与阶段进展

## 小结

> 本周统计周期：`2026.09.01-2026.09.07`；进展更新时间：`2026.09.07 17:35（北京时间）`。

本周围绕“更换提示词和大语言模型后，绿色营销传播结果是否仍然稳定”这一问题，完成新一轮稳健性实验框架与运行验证，并启动真实模型对照实验：

- 确定五模型、四种提示词的对照方案，覆盖 DeepSeek、Gemini 3.1、Gemini 3.8、Kimi 和 OpenAI，共 `5 × 4 = 20` 组实验条件。沿用历史 1,000 位研究用户、三类营销内容和 30 个传播批次，每批每类内容选择 20 位用户，每组计划形成 1,800 条判断，总目标为 `36,000` 条；本轮属于独立的稳健性实验，不与此前 36,400 位用户、109,200 次曝光的全量主实验混合计算；
- 完成五个模型的接入适配，并先后通过各模型的独立小规模真实请求验证。四种提示词分别保留原始表述、仅替换词汇、重排相同信息、增加结构化评价要求，保持受控差异和统一决策格式；同时完善模型身份、输出格式、用量记录和失败处理，避免把技术失败错误记为用户“不互动”。小规模验证通过只说明当时的请求可用，不代表后续数千次调用都能成功；
- 将上一阶段的“模型判断—概率实现—传播反馈”方法纳入本轮稳健性实验，继续区分模型给出的互动倾向与仿真最终实现的互动。完成面向教师的结果表、Excel 和 CSV 导出模块，按模型、提示词、用户群体和营销内容组织模拟结果，并另列模型判断及运行审计，为后续完整结果提供统一的展示与核对口径；
- 完成新运行入口相关的 176 项自动化测试，以及三项大规模离线演练。其中，五模型实验的离线演练完整覆盖 20 组条件、36,000 条判断和对应模拟实现，未调用真实模型。这些验证用于检查流程、计数和异常处理，不能代替真实实验，也不计入正式判断进度；
- 已启动真实模型实验，目前形成并保存 `8,850` 条有效判断及对应模拟实现记录：DeepSeek 的四种提示词条件全部完成，共 7,200 条；Gemini 3.1 在第一种提示词条件下完成 1,650 条。Gemini 3.8、Kimi 和 OpenAI 的本轮正式实验尚未启动，不能把“未运行”解释为这些模型验证失败；
- Gemini 3.1 随后的一次响应未形成完整的输入、输出及总 token 用量证据，触发既定的不可重试停机规则；由于实验按模型串行执行，后续条件也随之停止。已完成的 8,850 条有效结果与最后一条失败记录均保留并通过账本核对，失败记录没有计入有效判断。目前尚未确定证据是在上游、网关还是客户端处理时缺失，因此没有猜测补齐，也没有把本轮未完成结果作为完整五模型研究报告发布。

因此，本周工作可以概括为：**完成五模型、四种提示词的两阶段稳健性实验框架、模型接入与离线验证，并启动真实实验取得 8,850 条有效判断；当前因 Gemini 3.1 的用量证据缺失停止，尚未完成计划中的 36,000 条判断和完整模型对照。**

下一步将先定位 token 用量证据缺失的环节，明确保留已有有效数据、符合既定证据要求的恢复方案，验证后再推进剩余实验条件。待完整结果形成后，进一步比较不同提示词和模型接入条件下，三类营销内容及不同用户群体的模拟互动差异，整理为“研究方法—稳健性结果—限制”部分。在此之前，不根据当前不完整样本给出模型优劣排序，也不将模拟差异解释为现实营销效果或因果关系。
