# 本周工作进展报告（2026.08.18-2026.08.24）：锦江全量用户营销传播正式实验完成与结果发布

## 小结

> 本周统计周期：`2026.08.18-2026.08.24`；进展更新时间：`2026.08.24 15:00（北京时间）`。

本周完成了锦江酒店绿色营销全量用户主实验，并将经过核对的正式结果发布到研究网页：

- 完成全部 `36,400` 位研究用户与环保责任、实用品质、材料创新三类营销内容的仿真实验，共形成 `36,400 × 3 = 109,200` 条有效用户—内容判断，完整覆盖 30 个传播批次；前 29 批每类内容各处理 1,214 位用户，最后一批各处理 1,194 位用户；
- 最终审计发现，前期续跑轨迹导入的历史结果中有 3 条 Provider 失败记录，其中 2 条位于第 1 个传播批次。由于事后单独补写这些结果可能改变后续互动反馈和推荐顺序，本周没有采用局部替换，而是从第 1 批重新完成一条独立、严格的全量轨迹。最终 109,200 条判断全部成功，最终失败数为 0，模型身份和使用记录均完整；
- 全量仿真结果共记录点赞 92,954 次、评论 6 次、分享 214 次、忽略 16,026 次。以上数值用于描述固定用户数据、固定传播网络和固定实验规则下的模拟差异，不代表 Douyin 用户真实发生的互动，也不能直接解释为现实营销效果或因果关系；
- 完成结果表口径修正：`Run` 现明确表示实际传播轮次，按照 `Run = time_step + 1` 从 1 到 30 编号。正式结果按 `30 个 Run × 3 类内容 × 3 类用户群体` 展开为 270 行，并能严格汇总回 109,200 次总曝光；HTML、CSV 和 Markdown 数据说明使用同一口径；
- 将正式结果发布到 `https://abm.q1ngyuan.top/`。当前 Release 已通过 193 个文件的完整哈希核对、电脑端与移动端交互检查、结果下载检查及独立公网验收；发布与结果口径修正阶段没有重新调用大语言模型，也没有改写已经完成的正式实验 source；
- 历史 1,000 位用户实验、Primary–Shadow 对照、19 组推荐权重分析和 `4 Prompt × 4 Model` 稳健性证据继续保留，未与本次 36,400 位用户主实验混合计算。由于新旧实验同时改变了研究用户范围和使用模型，两者差异不能归因于单一因素。

因此，本周工作可以概括为：**完成了 36,400 位用户、三类营销内容和 30 个传播轮次的全量正式实验，形成并核对 109,200 条成功判断，修正 Run 口径，完成结果文件、正式网页发布和独立公网验收。**

下一步将继续完善研究网页的信息结构：以“机制说明”和“运行证据”作为顶层阅读方式，在两种视图中分别区分当前 Full-Pool 主实验与历史敏感性分析；保留历史机制图和历史记录，同时为全量实验补充信息粒度一致的机制图。完成展示结构确认后，再进一步整理三类内容、三类用户群体和 30 个传播轮次之间的描述性差异及研究限制。
