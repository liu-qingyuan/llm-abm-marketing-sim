# Ten-topic Report / Release

`ten_topic_release` owns exact admission of the reviewed Whole-sample, GPT parameter/index and four-model sources. `accept_ten_topic_sources` checks their pinned source identities, acceptance status and physical hashes, including all 2,800 GPT paths. It does not alter the earlier sources' deployment flags or accept arbitrary objects labelled Formal.

`collect_ten_topic_public_data` projects only public aggregates. It checks exclusive counts/denominators, matches displayed GPT means against per-seed path metrics, and checks four-model category-curve endpoints against the formal tables. New user identifiers and response/judgment banks never enter this projection. The historical download policy remains unchanged.

Report's `render_ten_topic_research` renders the four current research views in the existing editorial shell. Tables, interactive curves, CSV/JSON/SVG exports and the workbook use the same typed projection. `ten_topic_workbook_tables` owns the 17-sheet public interface; Release independently reads the ZIP/XML workbook cells and compares every value with that interface. This validates serialization, not a second independent research computation. The original research acceptances remain the independent research evidence.

`promote_ten_topic_release` creates a new immutable directory and sibling exact `abm-report-release-contract-v17`. It binds explicit sources, implementation commit, immutable workbook input, endpoint and complete inventory. Historical v16 assets are byte-preserved; the original HTML/manifest are retained under explicit single-topic names. It never overwrites an existing release or calls a Provider.

`validate_ten_topic_release` reconstructs the expected publication from the explicit inputs and compares all physical bytes, optionally including Deployment's isolated snapshot. Reconstruction shares Report/Release code with production and is a consistency check, not independent validation of the same research statistics. Exact source admission and prior research acceptances supply authenticity and experiment validation.

Deployment consumes only `ten-topic-v17-release-readiness-v1`, then requires the independent, canonical `abm-report-v17-deployment-authorization-v1`. The existing fresh rollback readback, candidate inventory/health, atomic `current` switch, public body verification, browser interactions and locked final readback remain mandatory. Host/domain/root/topology are not changed by this schema.

Statistics retain their original units: Whole sample is one realization over 109,200 exposures; parameter/index results are means and conditional Monte Carlo intervals over 100 behavior seeds; four-model results are 16 single-seed adaptive paths, with direct pairing confined to the common initial user panel. DeepSeek V4.1 Flash versus prior V4 Flash and Gemini gateway observability are disclosed. Network, sample and service-time changes are not isolated causal effects.
