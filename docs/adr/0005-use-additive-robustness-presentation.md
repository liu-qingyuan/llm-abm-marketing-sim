# ADR 0005: Prompt–Model Robustness 使用增量证据呈现

Status: Accepted

未来 Robustness presentation 保留当前 Concurrent Message report 的机制、Run Evidence、Demographic Shadow comparison 和 barrier 说明，再加入 Ranking Weight 与 Prompt–Model 结果。新 factorial 不重跑 Shadow；旧 Shadow evidence 继续绑定原始 Formal source，不能解释为新模型结果。任何 canonical release 都必须验证新旧 source lineage；本 ADR 不授权 Provider 调用、实现或部署。
